# Classification of Fruits Based on Color, Shape, and Texture Features

## Dataset
Fruits Classification Dataset from Kaggle: https://www.kaggle.com/datasets/utkarshsaxenadn/fruits-classification

## Features
- Color Histogram
- Shape Features
- GLCM Texture Features

## Classifiers
- Support Vector Machine (SVM)
- K-Nearest Neighbors (KNN)

## Requirements

pip install -r requirements.txt

## Run Training

python train_model.py

## Run Prediction

python predict.py

## Run Web Application

python web_application.py
